# Extra 8x16 glyphs for the Latin glyph table of translated text (the font builder merges this
# file over the 8x16 ISO 8859-1 font, fonts/x11/8x16.bdf): the Polish letters. Same conventions
# as the font they extend: one cell per glyph, 16 rows of 8 pixels, '#' = ink, NOT emboldened
# (an engine that wants bold text emboldens at run time). The baseline is row 13, rows 14-15
# are the descender.
#
# ó and Ó are not here: the base font has them. The rest were drawn from the base font's own
# glyphs: base letter + diacritic. Acute = the base font's own from é / É; capitals with an
# accent lose two body rows, as its É does, so the accent fits in rows 0-2; dot above 2x2;
# ogonek a two-row hook under the right side; stroke a diagonal through the stem. Edit freely:
# this file is the source, nothing regenerates it.
#
# Block: "U+XXXX <char>" then 16 rows.
